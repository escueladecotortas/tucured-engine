Web del Cliente (WordPress/Shopify)

Esta página simula un entorno externo donde el CSS global podría entrar en conflicto con nuestros componentes. Gracias al Shadow DOM del Stitch SDK, nuestro widget mantiene su soberanía estética.

El widget de arriba es un Gantt Enterprise inyectado dinámicamente. Aunque el fondo de esta web es blanco y minimalista, el widget conserva su atmósfera oscura y neón de NEXUS.
